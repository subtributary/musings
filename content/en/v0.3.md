# Version 0.3 - Search

With many documents, a search feature is a required convenience.
In version 0.3, content can be searched via the command-line or the website.

## New: Search algorithm

Musings implements a variant of the BM25 algorithm.
Each word's importance is calculated based on its rarity in the corpus.
When a word is searched, documents with that word are given a higher rank,
and rare words boost the ranking of documents that contain them even more.

The variant of BM25 that Musings implements is the BM25F algorithm.
It extends the BM25 algorithm by adding weighted document streams.
Musings uses this to give title matches more weight than document matches.

BM25 and its variants require a good tokenization algorithm,
which is hard to accomplish when the target audience is _global_.
To better support languages with very different writing systems,
Musings adapts its tokenization behavior dynamically in response to script changes.

## New: Index tools

The new `index` tool builds the search index for Musings.
It can rebuild the entire index or index a specific file.

The new `search` tool allows searching the index without running the website.

For usage instructions on the tools, run them with the `--help` parameter. 

## New: Website content listing

The website's front page lists the content in order of publication date.
The search box at the top will sort the list by best match.

## What's next

The original plan was to add plugin support next,
but I feel like we need to do a polishing step next instead.
Therefore, the roadmap has changed:

 * Version 0.4 will focus on polishing and testing.
 * Version 0.5 will add support for plugins.
 * Version 0.6 will be a minor update with changes requested by supporting projects.
 * Version 0.7 will be a minor update with changes requested by a derivative project.
 * Version 1.0 will be the first stable release.

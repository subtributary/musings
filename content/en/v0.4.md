# Version 0.4 - Polishing and testing

I will fill out this document later. For now it is a place for notes.

## Stuff I did:

 * Static files are no longer localized. 
 * HTTP HEAD requests for content now supported.
 * Config location changes:
   * System configuration is in "./data/config.json".
   * Deployment configuration is via parameters or ".env".
 * Revamped search. It is now much cleaner.
 * Command-line error feedback is now cleaner.
 * Created logo for Musings
 * Content is indexed at startup instead of by a separate program.
 * Replaced PicoCSS with Drip.
 * Added image thumbnails for posts.

# Version 0.4 - Polishing and testing

After months of hard work, I present a stable solution for content publishing.

I am tempted to bump the version to v1.0, but it is not time for that yet.
While Musings is stable, it is lacking some planned features.
It is not finished.

## Changes in v0.4

### New: Musings icon

Musings has its own icon!

![Musings logo](../_shared/logo.svg)

The Subtributary logo has been simplified to just the circle border so it can enclose product icons.
The nib in the center is modified from a public domain SVG that I found.

### New: Post thumbnail

Thumbnails can be added to posts now.
This really pretties up the otherwise plain default index page.

![Bench in a public park](../_shared/v0.4.jpg)

For the version 0.4 thumbnail, I chose a picture from one of my favorite parks in Seoul.
There isn't a particular attraction in the park.
It's simply a peaceful place to sit and enjoy the beauty of the world.

### Change: Stylesheet library replaced

I was using Pico for the base stylesheet because it is simple and unobtrusive.
The problem is that it lacks support for all of the writing directions that we need.
In fact, I found no stylesheet that met our globalization needs.

[Drip](https://github.com/subtributary/drip) is the newest product of Subtributary.
It is a base stylesheet that supports ten writing directions.

Drip handles our layout so that I can focus on branding.
Our CSS was greatly simplified by this switch.

### Change: Static files are no longer localized

Static file localization felt like a good idea in the beginning,
but the feature proved to be more confusing than helpful.
Static files are now just plain and simple regular files.

If static file localization is needed, it can be handled in frontend code.
The default frontend demonstrates one way of handling this in its font choices.

### Other changes

* Added Support for HTTP HEAD requests.
* Changed config sources -- see the documentation for details.
* Prettied up command-line error feedback.
* Simplified indexing by handling it in the server instead of a separate tool.
* Various internal code improvements.

## What's next?

The current plan is to implement plugins next.
This will add support for YouTube videos and other embedded content.

However, I want to take a short break first.
I have been working so very hard on this product, and I want to take some time to enjoy it.
I will be using Musings to create a fun little website.

After that, the roadmap currently looks like this:

* Version 0.5 will add support for plugins.
* Version 0.6 will be a minor update with changes requested by supporting projects.
* Version 0.7 will be a minor update with changes requested by a derivative project.
* Version 1.0 will be the first stable release.
